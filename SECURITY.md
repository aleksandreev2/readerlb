# Security Policy

## Supported versions

До 1.0 поддерживается только последняя опубликованная стабильная версия ReaderLB.

Критические исправления безопасности и риски потери данных выпускаются вне обычного графика.

## Reporting a vulnerability

Не публикуйте уязвимость, секрет или сценарий потери данных в открытом issue.

Предпочтительный канал — **GitHub Security Advisory / private vulnerability reporting** этого репозитория, если он доступен в интерфейсе GitHub.

Если private reporting недоступен, свяжитесь с владельцем репозитория через GitHub-профиль и укажите, что речь идёт о приватном security report.

В отчёте полезно указать:

- версию ReaderLB;
- версию Android;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- затрагивает ли проблема существующие локальные данные RanobeLib.

Не прикладывайте приватные EPUB или пользовательские данные без явной необходимости.
