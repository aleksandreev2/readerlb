> **ReaderLB — независимый проект и не является официальным приложением RanobeLib.**

## Что такое ReaderLB

ReaderLB помогает добавить локальную книгу в библиотеку RanobeLib без ручной разборки EPUB и возни с файлами глав.

Вы выбираете книгу — ReaderLB сам:

- находит главы и их нумерацию;
- переносит обложку и встроенные иллюстрации;
- поддерживает главу 0 и дробные номера глав;
- проверяет структуру книги перед записью;
- добавляет недостающие главы в уже существующий локальный тайтл;
- умеет создать переносимый пакет для другого телефона.

ReaderLB не является отдельной онлайн-читалкой и не работает с аккаунтом RanobeLib. Его задача — подготовить и безопасно импортировать **локальную** книгу.

## Скачать и установить

Актуальная стабильная версия публикуется только в **GitHub Releases**:

**[Открыть последнюю версию ReaderLB](https://github.com/aleksandreev2/readerlb/releases/latest)**

Текущая стабильная версия: **1.0.0**.

Минимальная версия системы: **Android 10**.

После скачивания APK Android может попросить разрешить установку приложений из этого источника. Это обычное системное подтверждение для APK, установленного не из Google Play.

## Быстрый старт

1. Скачайте APK из [GitHub Releases](https://github.com/aleksandreev2/readerlb/releases/latest) и установите ReaderLB.
2. Откройте приложение и нажмите **«Добавить новеллу»**.
3. Выберите файл **EPUB**, **TXT** или **.readerlb.zip**.
4. Дождитесь анализа книги и проверьте найденные главы.
5. Запустите импорт.
6. Если у ReaderLB есть доступ к локальной папке RanobeLib, книга будет добавлена напрямую.
7. Если Android не позволяет такой доступ, ReaderLB подготовит переносимый ZIP вместо небезопасной или заведомо неработающей записи.

Исходный EPUB или TXT при этом не изменяется.

## Какие файлы поддерживаются

| Формат | Для чего |
| --- | --- |
| **EPUB 2 / EPUB 3** | Основной формат. ReaderLB извлекает главы, обложку и иллюстрации. |
| **TXT** | Импорт текстовых книг с определением глав. |
| **.readerlb.zip** | Готовый переносимый пакет ReaderLB для переноса новеллы между устройствами. |

Обычные ZIP-файлы не считаются пакетами ReaderLB автоматически: приложение проверяет их содержимое и формат.

## Если новелла уже есть в RanobeLib

ReaderLB не создаёт дубликат только из-за повторного импорта.

При совпадении локального тайтла приложение старается:

- сохранить уже существующие главы;
- добавить только недостающие;
- не перезаписывать существующий текст автоматически;
- проверить новые файлы перед публикацией метаданных;
- не оставлять библиотеку в полуобновлённом состоянии при ошибке.

Это удобно, например, когда сначала были импортированы главы 1–300, а позже появился EPUB с продолжением.

## Android 11 и новее

Начиная с Android 11 система сильно ограничивает доступ одного приложения к папкам другого приложения внутри `Android/data`.

Поэтому возможны два сценария:

**Прямой импорт.** Если у ReaderLB уже есть действующее сохранённое разрешение на папку локальной библиотеки RanobeLib, новые главы можно записать напрямую.

**Переносимый пакет.** Если Android не даёт такой доступ, ReaderLB не пытается обходить системные ограничения. Вместо этого приложение сохраняет подготовленный пакет в `Downloads/ReaderLB`.

Это ограничение Android, а не ошибка ReaderLB.

## Перенос книги на другой телефон

Для локального тайтла можно выбрать **«Поделиться новеллой»**.

ReaderLB создаст файл `.readerlb.zip`, содержащий подготовленную книгу, главы, обложку и иллюстрации.

На другом устройстве:

1. установите ReaderLB;
2. откройте полученный `.readerlb.zip` через ReaderLB;
3. подтвердите импорт.

Повторно искать исходный EPUB и разбирать его не требуется.

## Библиотека ReaderLB

Если ReaderLB имеет доступ к локальной библиотеке RanobeLib, приложение показывает найденные локальные тайтлы с обложками и количеством глав.

В библиотеке доступны:

- поиск;
- сортировка;
- просмотр информации о тайтле;
- удаление локального тайтла с подтверждением;
- создание переносимого `.readerlb.zip`.

ReaderLB не отправляет список вашей библиотеки на свой сервер.

## Обновления ReaderLB

Стабильные обновления публикуются в [GitHub Releases](https://github.com/aleksandreev2/readerlb/releases).

ReaderLB умеет проверять наличие новой версии и передавать APK стандартному установщику Android. Перед установкой приложение проверяет пакет и целостность загруженного файла.

Android или оболочка производителя телефона всё равно может потребовать дополнительное подтверждение установки.

## Безопасность и приватность

Разбор книг и работа с локальной библиотекой выполняются **на устройстве**.

ReaderLB не отправляет на сервер:

- текст книг и глав;
- обложки и иллюстрации;
- список локальных тайтлов;
- историю импортов.

В приложении нет Firebase Analytics и Crashlytics.

Проверка обновлений обращается к GitHub. Подробнее о данных и сетевых запросах: **[PRIVACY.md](PRIVACY.md)**.

## Если что-то не работает

Сначала проверьте:

1. установлена ли [последняя стабильная версия](https://github.com/aleksandreev2/readerlb/releases/latest);
2. открывается ли исходный EPUB/TXT обычным файловым менеджером или читалкой;
3. не был ли отозван ранее выданный доступ к папке RanobeLib;
4. хватает ли свободного места на устройстве.

Если проблема остаётся:

- **[создайте Bug Report в GitHub Issues](https://github.com/aleksandreev2/readerlb/issues)**;
- укажите модель телефона и версию Android;
- приложите шаги, после которых возникает ошибка;
- при возможности приложите скриншот или текст ошибки.

Не прикладывайте публично приватные книги, токены, ключи подписи или другие секреты.

Более подробная инструкция: **[SUPPORT.md](SUPPORT.md)**.

## Проверка APK

Для каждого стабильного релиза публикуется файл SHA-256 рядом с APK.

Например, для версии 1.0.0:

```text
ReaderLB-1.0.0.apk
ReaderLB-1.0.0.apk.sha256
```

Релизные APK также собираются в GitHub Actions постоянным release-ключом и получают GitHub build provenance attestation.

## О проекте

ReaderLB создан для удобной работы с локальными книгами RanobeLib и развивается как открытый проект.

Исходный код открыт, а предложения и сообщения об ошибках принимаются через [GitHub Issues](https://github.com/aleksandreev2/readerlb/issues).
