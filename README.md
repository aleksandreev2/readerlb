# ReaderLB

Android-приложение, которое подготавливает пользовательские EPUB/TXT под локальный формат офлайн-читалки RanobeLib.

## Что уже работает

- импорт EPUB;
- импорт TXT;
- извлечение названия, автора, описания и обложки из EPUB;
- автоматическое определение глав;
- выбор диапазона глав;
- генерация `info.json`, `chapters.json` и ZIP каждой главы с `data.txt`;
- прямое добавление в выбранную пользователем папку `Android/data/ru.libappc/files/book`, если Android разрешает доступ;
- запасной вариант: готовый ZIP сохраняется в `Downloads/ReaderLB`;
- история импортов;
- безопасное обновление уже существующего локального тайтла: добавляются только отсутствующие главы, старые ID/главы не перезаписываются;
- транзакционная запись с резервной копией метаданных и восстановлением после прерванного обновления;
- интерфейс на Jetpack Compose в синей редакционной стилистике по согласованному макету.

Формат проверен на реальном приложении RanobeLib: локальный тайтл отображается карточкой и главы открываются штатной читалкой.

## Поток пользователя

1. Нажать **Добавить новеллу**.
2. Выбрать EPUB/TXT.
3. Проверить название и, при необходимости, диапазон глав.
4. Один раз указать папку RanobeLib `.../files/book` для прямого импорта.
5. Нажать **Импортировать**.

Если системный файловый менеджер Android 11+ запрещает выбирать `Android/data`, прямой импорт можно выключить — приложение подготовит ZIP для ручного переноса.

## Ограничения MVP

- DOCX пока не импортируется.
- ZIP поддерживается как EPUB-контейнер.
- Сложное форматирование EPUB (встроенные изображения, таблицы, произвольные CSS-стили) пока упрощается до текста, цитат и разделителей.
- Прямой доступ к `Android/data` зависит от версии Android/проводника.

## Обновления

ReaderLB 0.5 добавляет проверку GitHub Releases и полуавтоматическую установку
обновлений. Исторические тестовые сборки 0.4.x были подписаны разными CI-ключами,
поэтому переход с них на стабильный канал требует один раз удалить старую
версию и установить новую. Причина и контрольные отпечатки описаны в
`docs/SIGNING_MIGRATION.md`.

## Сборка

Проект собирается GitHub Actions. Локально нужен JDK 17, Android SDK 35 и Gradle 8.9:

```bash
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
