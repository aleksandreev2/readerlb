# ReaderLB

ReaderLB — Android-приложение для импорта **EPUB, TXT и переносимых пакетов ReaderLB** в локальную библиотеку RanobeLib.

Приложение само разбирает книгу, находит главы, обложку и иллюстрации и добавляет их в локальную библиотеку. Если тайтл уже существует, ReaderLB добавляет недостающие главы и не перезаписывает существующие автоматически.

> ReaderLB — независимый open-source проект и не является официальным приложением RanobeLib.

## Скачать

**Минимальная версия Android: Android 10.**

Первая публичная стабильная версия ещё готовится. После её выпуска APK будет публиковаться только в [GitHub Releases](https://github.com/aleksandreev2/readerlb/releases).

Тестовые сборки до первого стабильного релиза доступны в [GitHub Actions](https://github.com/aleksandreev2/readerlb/actions). Для обычного использования лучше выбирать артефакт **ReaderLB-optimized-test** из последней успешной сборки.

## Что умеет ReaderLB

- импортировать EPUB и TXT;
- находить главы, обложку и иллюстрации;
- поддерживать главу 0 и дробные номера глав;
- добавлять новые главы в уже существующую локальную новеллу;
- показывать локальную библиотеку с поиском и обложками;
- удалять локальные тайтлы с подтверждением;
- переносить новеллу на другой телефон через файл `.readerlb.zip`;
- проверять обновления приложения через GitHub Releases;
- по желанию уведомлять о новых стабильных версиях.

## Как пользоваться

1. Установите ReaderLB и откройте приложение.
2. Нажмите **«Добавить новеллу»**.
3. Выберите EPUB, TXT или `.readerlb.zip`.
4. При первом импорте укажите локальную папку RanobeLib через системный выбор папки Android.
5. Проверьте найденные главы и запустите импорт.
6. Откройте RanobeLib — импортированный тайтл появится в локальной библиотеке.

Если новелла уже есть в библиотеке, ReaderLB старается обновить её безопасно: существующие главы не заменяются автоматически, а изменения записываются транзакционно.

## Android 11 и новее

Android ограничивает прямой доступ приложений к некоторым папкам. Поэтому на части устройств и прошивок папку локальной библиотеки приходится выбирать вручную через системное окно Android.

Если прямой импорт недоступен, ReaderLB умеет подготовить переносимый пакет `.readerlb.zip`, который можно сохранить или передать на другой телефон.

## Перенос новеллы между телефонами

В карточке локального тайтла можно выбрать **«Поделиться новеллой»**. ReaderLB создаст переносимый `.readerlb.zip`.

На другом телефоне достаточно открыть этот файл через ReaderLB — повторно разбирать исходный EPUB не нужно.

## Приватность

ReaderLB обрабатывает книги и локальную библиотеку **на устройстве**.

Приложение не отправляет на сервер ReaderLB:

- текст книг и глав;
- обложки и иллюстрации;
- список локальных тайтлов;
- историю импортов.

В приложении нет Firebase Analytics или Crashlytics.

Проверка обновлений обращается к GitHub. Push-уведомления о релизах выключены по умолчанию; при их включении используется Firebase Cloud Messaging только для доставки уведомлений.

Подробнее: [PRIVACY.md](PRIVACY.md).

## Если что-то не работает

Перед созданием issue проверьте, что:

- установлена актуальная сборка ReaderLB;
- приложению заново выдан доступ к папке локальной библиотеки;
- исходный EPUB/TXT открывается и не повреждён.

Сообщить об ошибке или предложить улучшение можно в [GitHub Issues](https://github.com/aleksandreev2/readerlb/issues).

Если проблема связана с уязвимостью или риском потери данных, не публикуйте детали в обычном issue — используйте [SECURITY.md](SECURITY.md).
